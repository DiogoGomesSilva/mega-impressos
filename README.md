# Mega Impressos

Site institucional da Mega Impressos, gráfica rápida em Igarassu – PE (design "Opção A – Editorial").

## Como ver

Abra `index.html` no navegador. Não há build nem dependências.

## Estrutura

- `index.html`: página única (início, serviços, portfólio, sobre, contato)
- `css/style.css`: estilos e responsividade
- `img/`: ilustrações vetoriais (SVG) dos serviços e do portfólio; troque por fotos reais quando tiver
